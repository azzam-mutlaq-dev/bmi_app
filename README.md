# bmi_app

A Flutter learning project for experimenting with form-based input, authentication UI, navigation, and BMI-related screens.

## Current scope

The repository currently includes:

- A Flutter application entry point.
- Login and password input UI.
- Form-based screens and navigation components.
- BMI-related screens under the application modules.
- Android, iOS, web, Linux, macOS, and Windows project scaffolding generated by Flutter.

This is an educational/experimental project. It should not be presented as a production medical or health product.

## Technology

- Flutter
- Dart
- Material UI

## Run locally

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Verify the local setup:

   ```bash
   flutter doctor
   ```

3. Fetch dependencies and run the app:

   ```bash
   flutter pub get
   flutter run
   ```

To run the test suite:

```bash
flutter test
```

## Notes and limitations

- The repository is an active learning project and its UI/data flows may change.
- Authentication screens are UI experiments; no production authentication backend is documented here.
- Health-related calculations and interfaces should be validated before any real-world use.
- No screenshots are included because no verified project screenshots are currently stored in the repository.
